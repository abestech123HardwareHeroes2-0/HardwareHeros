# Security Policy

## Supported Versions

Security fixes are provided for the latest version of HardwareHeroes-2.0. Reports about older versions will be assessed individually.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

Use the repository’s **Report a vulnerability** option on the **Security** tab to send a private report. Include, if possible:

- A description of the vulnerability and its potential impact
- The affected version, commit, or component
- Steps to reproduce the issue safely
- Any suggested mitigation or fix

We will review reports as promptly as possible and provide updates through the private report. Please allow maintainers time to investigate and address the issue before disclosing it publicly. Do not access, modify, or delete data that does not belong to you, or disrupt services while investigating.
