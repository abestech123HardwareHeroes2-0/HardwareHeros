A small Python command-line utility

A clear view of your system.

Hardware Heroes 2.0 prints essential information about the computer where you run it: processor, physical cores, logical threads, total memory, and operating system.

Get started ↓ Explore the source

Python 3.9+ · Requires psutil · MIT licensed

Terminal · example format
$ python detect-hardware.py

Hardware Detection Results:
---------------------------
CPU: [processor name]
CPU Cores: [physical core count]
CPU Threads: [logical thread count]
RAM: [total memory in GB]
Operating System: [system and release]
Illustrative fields only; actual values depend on the machine running the script.
What it reports

The useful basics, in one quick report.

A focused snapshot of the system, printed directly in your terminal.

CPU

Processor

Displays the processor identifier provided by Python’s platform information.

02

Cores and threads

Reports physical CPU cores and logical CPU threads when the system provides them.

RAM

Total memory

Shows total system memory in gigabytes using the psutil library.

OS

Operating system

Prints the operating system name and release reported by the running system.

Straightforward by design

One script. A readable summary.

Run the utility from a terminal to see a short report about the computer running the script. It is a lightweight Python project—not a browser-based hardware scanner or hosted monitoring service.

  • ✓Uses Python’s built-in platform module for processor and operating-system details.
  • ✓Uses psutil for CPU counts and total memory.
  • ✓Prints its report in the terminal; the website does not receive it.

Requirements and setup

Get running in three steps.

Hardware Heroes 2.0 is distributed as source code in this repository. It is not currently published as a separate pip package or installer.

Requirements

Python3.9 or later
Dependencypsutil
InterfaceCommand line
The only third-party dependency is psutil, used to read CPU counts and memory information.

1. Get the source

Clone the repository and enter its folder.

git clone https://github.com/abestech123HardwareHeroes2-0/HardwareHeroes-2.0.git
cd HardwareHeroes-2.0

2. Install the dependency

Install psutil with the Python interpreter you intend to use.

python -m pip install psutil

3. Run the utility

Start the script; the report appears in your terminal.

python detect-hardware.py
Where it runs

Know what the report represents.

The Python script reports the environment in which it is executed. The static website itself does not run the script.

Run locally

When started on your computer, the script reads information from that computer and prints it to your terminal.

Run in GitHub Actions

In a workflow, the script reports the GitHub-hosted runner’s environment—not your personal computer.

Visit this website

This static page does not scan visitor devices, execute the utility, or collect hardware information.
