A lightweight Python utility

Know what’s inside your machine.

Hardware Heroes 2.0 reports essential system information—processor, physical cores, logical threads, installed memory, and operating system—from the computer where you run it.

What it reports

The essentials, without the noise.

A small command-line tool focused on a concise, readable snapshot of your system.

▤

Processor

Displays the processor identifier reported by Python’s platform information.

◫

Cores and threads

Shows physical CPU core count and logical processor count when available.

▦

Installed memory

Reports total system memory in gigabytes using the psutil library.

◎

Operating system

Prints the operating system name and release reported by the running system.

Simple by design

One script. A clear system summary.

Run the utility from a terminal to print a short report about the computer running it. It is designed as a lightweight Python project—not a browser-based hardware scanner or hosted monitoring service.

  • ✓Uses Python’s built-in platform module for processor and OS details.
  • ✓Uses psutil to read CPU counts and total memory.
  • ✓Prints results in your terminal; it does not upload them to this website.

Requirements and setup

Everything you need to run it.

The project uses one third-party Python dependency. Install it in your environment, then run the script from the repository directory.

Runtime requirement

Python 3.9 or later

Use a Python installation available in your terminal. The project is a script and is not currently published as a pip-installable package.

Dependency: psutil

Dependency

psutil

Reads CPU counts and total physical memory. Install it with pip before running the utility.

Package details: PyPI — psutil

Package status: Hardware Heroes 2.0 is currently provided as source code in this GitHub repository. There is no separate Hardware Heroes package or installer to download.

Get the source

Clone or download the repository from GitHub, then open a terminal in its directory.

Install the dependency

Run this command using the Python interpreter you plan to use:

python -m pip install psutil

Run the utility

Start the script and read the report in your terminal:

python detect-hardware.py

Quick start
python -m pip install psutil
python detect-hardware.py
Local execution

Understand what runs—and where.

This website is a static project page. The Python script runs only when you execute it locally or within a workflow such as GitHub Actions.

Your computer

When run locally, the script reads information from the machine on which it is running and prints it to the terminal.

GitHub Actions

When run in Actions, it reports the GitHub-hosted runner’s environment—not your personal computer.

This website

The page does not scan visitor devices, execute the Python tool, or collect hardware information.
