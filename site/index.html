Python hardware utility

Hardware Heroes 2.0

A small Python project that detects and displays basic information about a computer’s CPU, memory, and operating system.

Features

  • CPU information and core counts
  • Total installed RAM
  • Operating system and version

Run it locally

Install Python 3.9 or later, then run these commands from the project directory:

python -m pip install psutil
python detect-hardware.py
